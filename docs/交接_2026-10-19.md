## 3. "记录"做了什么（最新的、还没验的那块）

**作者定下的：**

- 记：总次数、日面/月面次数和百分比、当前连续、最长连续、今天、转得最多的一抛（圈）、一共翻了几圈、从哪年哪月开始、清零（要确认）。第 100/500/1000 次落定时底部那行字多一句 `· No. 100`。
- **两面叫"日面 / 月面"，不叫"正 / 反"**（需求规定不给两面预设含义）。作者还没表态，他要改成正反也行。

- 只存数字、只存本机、不上传；关 App 再开还在；清零只清记录，不动硬币朝上那面。
- 右上角小图标：**C[一摞四枚硬币，顶面一颗小星]in**，系统无衬线·**常规**，平时三成亮，按下变亮。硬币缝、顶面那圈边、小星都是挖空的。**不要**"跟着上次结果翻一下"（作者否了）。
- 卡片字体：**无衬线·细**，英文标签全大写、字距拉开（作者选的 B）。
- 底部 `Coin: Luna` 的**字体不变**（衬线体）。

**文件：** `Model/FlipStats.swift`（新）、`App/RecordViews.swift`（新：图标、硬币堆画法、卡片）、`Logic/CoinStore.swift`（存取 `flipStats`）、`Logic/CoinController.swift`（`settle()` 里记一次、`resetStats()`、`milestone`）、`App/CoinFlipApp.swift`（放图标、暗幕、卡片；StatusLine 加 milestone）、`CoinFlipTests/FlipStatsTests.swift`（新）。

## 4. 下一步：爽感 / 能一直盘玩（作者还没选）

作者原话："有没有什么可以增加'爽感'的方法"、"可以让用户持续盘玩"。还转述了一条**用户建议："抛投时加计数淡入淡出特效"**。

**我对用户建议的意见（已告诉作者）：** 方向对，但**抛的过程中不能数"半圈"**——起始面看得见，数字一停奇偶就把结果剧透了。改成：

- **落地后淡出"这一抛转了 7.5 圈"**（一两秒淡掉）
- **破纪录时变成"新纪录 · 14 圈"** + 稍重的震动（跟"记录"里的"转得最多的一抛"连上）

**候选清单（编号是给作者看时用的）：**

第一轮提的（手上 / 耳朵 / 眼睛）：

1. 蓄力震动：上拖时震动由轻到重、硬币微颤，松手一记干脆的震
2. 空中转动感：翻转时连续轻"嗡"，转得快就密
3. 金属余音：落地"啪"之后短短的"嗡——"，扔得越高越长
4. 连中提示：同一面连 3 次以上，落地声音调悄悄升高
5. 落地顿一下：重落地时画面停约 0.05 秒 + 极小镜头抖动（打击感）
6. 落地光圈：地面蓝色微光从硬币下荡开一圈
7. 大力抛的慢镜头：只在很用力时最高点放慢一下
8. 结果亮相：停稳时币面一道高光扫过

第二轮提的（能一直盘）：

- **落地圈数 + 新纪录提示**（回应用户建议，最小最快）
- **包浆**（我最推荐）：抛得越多硬币越亮越温润，跟总次数挂钩，只改材质参数，几乎不卡。协作约定里原先的候选"岁月磨损"就是这个思路
- **转到停的"欧拉盘"收尾**：横拨自旋结尾越躺越平、越转越快、"嗡嗡嗡——啪"
- **颠硬币计数**：基于 P13 的上下摇颠，连续颠住就计数、断了归零、记"最多颠了几下"（等 P13 验完）
- **稀有事件：立起来**：T25 边缘立币当极小概率彩蛋，卡片里记"立起来过 N 次"
- **个人纪录全家桶**：抛得最高 / 颠得最多 / 连续最长，破纪录时落地后淡淡提示

**我建议的顺序：** 落地圈数 + 新纪录 → 包浆 → 欧拉盘收尾 → 颠硬币计数；第一轮里先挑 1 蓄力、5 顿帧、3 余音。
**注意：** 画面类（5、6、7、8、包浆）每做一样数 15 抛看卡顿；全部要克制、别像玩具；"减少动态效果"模式下关掉抖动和慢镜头。
