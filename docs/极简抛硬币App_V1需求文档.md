# 极简抛硬币 App V1 需求文档

- 版本：V1
- 平台：仅 iPhone，仅竖屏
- 产品定位：一枚存在于数字世界里的沉静硬币，以金属光影、拟真动画、声音和触觉，为犹豫中的用户提供一次简洁的决策仪式。
- 产品原则：离线运行、无商业化、无常驻操作界面；功能围绕“一枚硬币、一次上划、一个结果”展开。

## 1. 核心功能点

### 1.1 全屏硬币呈现

- 打开 App 即进入全屏三维场景，中央呈现一枚具有精细浮雕与金属质感的硬币。
- 主场景无常驻按钮、文字、设置图标、菜单栏和状态栏。
- 允许两类临时视觉元素：首次使用的光点手势引导，以及长按唤出的硬币风格选择器。
- 手机倾斜时，仅改变金属高光与环境倒影，不通过陀螺仪驱动硬币本体移动或倾斜。

### 1.2 三种原创硬币风格

- 默认风格：现代银色纪念币。
- 可切换风格：东方青铜古币、古典深金硬币。
- 三款均采用原创“日／月”正反面主题，分别按现代、东方、古典风格雕刻。
- 参考现实硬币的浮雕、齿边、包浆和金属质感，不直接复刻真实货币图样。
- 不为日／月规定“是／否”等固定含义，由用户自行赋予选择意义。
- 风格切换同时改变造型、材质、视觉重量感、弹跳表现、声音和触觉；不改变结果概率。

### 1.3 上划抛掷与随机结果

- 使用屏幕上划触发抛掷，不设置“点击抛掷”按钮。
- 每次有效抛掷开始时，独立随机确定日面或月面结果，两面概率各为 50%。
- 采用“随机结果 + 物理感动画”：最终朝上的一面必须与本次预先确定的结果一致。
- 上划越快，抛掷越高、翻滚越快；高度、速度和时长设置合理上下限，具体映射在真机原型中调校。
- 动画包含脱手、腾空翻滚、落地，以及与力度和风格匹配的余震弹跳。
- 从抛掷开始到硬币完全稳定，忽略再次上划；不排队执行，也不叠加推力。
- 落地后，结果面朝上静置，直到用户再次有效上划；同一次使用中不自动恢复悬浮。

### 1.4 同步音效与触觉反馈

- 脱手瞬间提供轻巧触觉反馈，首次落地提供精准的单次撞击反馈。
- 较高抛掷的落地余震与弹跳，采用逐渐衰减的反馈。
- 配置手指摩擦、空中风声、金属碰撞等音效，与动画和触觉事件同步。
- 三种风格分别匹配各自的声音与震感，形成一致的材质感受。
- 音效遵循系统静音状态和媒体音量，不提供额外的声音开关。
- 静音时保留动画与设备、系统允许的触觉反馈；触觉不可用时仍可完成抛掷。

### 1.5 隐蔽硬币风格切换

- 在待抛状态长按硬币 2 秒，唤出风格选择器。
- 当前主硬币隐去，三枚缩略硬币横向展开。
- 点击任意一枚完成切换，选择器自动收起，恢复主场景。
- 切换风格不生成新的抛掷结果，保持当前日／月面含义一致。
- 在本机记住上次选择；再次启动时使用该风格。
- 此功能作为隐藏彩蛋，不提供首次引导或常驻入口。

### 1.6 一次性上划引导

- 首次使用时，用半透明光点演示上划，不显示文字提示。
- 用户完成首次有效上划抛掷后，引导消失；此后启动不再出现。
- 在本机保存引导完成标记。
- 引导只演示上划，不演示长按风格切换。

### 1.7 启动、后台与中断处理

| 情况 | 行为 |
| --- | --- |
| 首次安装、尚无抛掷结果 | 使用现代银色纪念币，轻微悬浮呼吸，展示一次性上划引导；初始展示面不视为抛掷结果。 |
| 彻底关闭后重新启动 | 恢复上次风格及最后一次结果，以该结果面朝上轻微悬浮呼吸，等待新的抛掷。 |
| 正常抛掷完成 | 结果面朝上静置，保存本次结果，完全稳定后接受下一次上划。 |
| 抛掷中切后台或被来电打断 | 立即停止声音与触觉，直接落定为本次已经确定的结果并保存；返回后静置，不续播、不重新随机。 |
| 未抛掷时切后台并返回 | 保持当前待抛状态；普通后台恢复不按冷启动重新播放悬浮效果。 |

- 悬浮呼吸使用小幅上下浮动和缓慢倾斜，与陀螺仪光影联动相互独立。
- 后台停止动画、声音、触觉与传感器更新，避免持续消耗资源。

### 1.8 系统偏好与本机保存

- 开启系统“减少动态效果”时，改用轻微抬起与落定的简化动画，省去高速翻滚；保留符合系统策略的音效与触觉。
- 减少动态效果模式下，静止展示取代循环悬浮呼吸和倾斜。
- 仅在本机保存：上次选择的硬币风格、最后一次抛掷结果、首次引导完成标记。
- 每次新结果覆盖上一次结果，不形成历史列表，不累计正反面次数，不上传任何数据。

## 2. 目标用户

- **容易陷入反复权衡的人**：在两个选择之间迟迟无法行动，需要一个外部信号打破僵局，或借结果看清自己的偏向。
- **日常选择困难的人**：面对吃什么、先做哪件事等小选择，希望通过单手操作快速结束纠结。
- **偏好极简审美与数字禅意的人**：重视材质、光影、声音和触觉，喜欢把玩有质感的数字物件。

## 3. 最核心的使用场景

### 3.1 核心场景：从犹豫到看清倾向

用户独自在安静的环境中，面对两个选择反复权衡。在心中为日面、月面赋予对应含义后打开 App，上划抛起硬币。硬币以与手势力度相符的动画落定，声音与触觉共同强化“结果落定”的瞬间。用户看到结果时，可以选择执行，也可以从自己的第一反应中发现真正的偏向。

核心使用链路：打开 App → 在心中对应两个选择 → 上划 → 硬币落定 → 看清结果或自身倾向。

### 3.2 次要场景：快速结束日常小选择

用户站在餐厅门口或安排日常事务时，竖屏单手上划一次，即可得到日／月结果。无需登录、输入选项或查看历史。

### 3.3 次要场景：把玩与放松

用户没有具体决策需求，只通过倾斜手机观察金属高光，或上划感受不同风格的碰撞声音和触觉。硬币保持克制、沉静的呈现。

## 4. 「这一版先不做」

- **网络与服务端**：不接入网络服务、远程配置、在线资源、埋点或第三方分析服务；所有核心资源随 App 提供。
- **商业化**：不接入广告，不做内购、订阅、付费弹窗或开屏倒计时。
- **账号与云同步**：不做登录、用户账户或跨设备数据同步。
- **历史与统计**：不做抛掷记录列表、正反面次数、概率统计或行为记录；本机仅保留最后一次结果及必要偏好。
- **选项输入**：不允许输入、编辑或保存自定义决策文字，不把日／月固定解释为“是／否”。
- **常规操作界面**：不做常驻抛掷按钮、设置齿轮、汉堡菜单、导航栏或常驻结果文字。
- **纯物理结果模式**：不让复杂碰撞模拟决定结果，不提供随机／物理玩法切换。
- **运动中追加操作**：不做空中重复抛掷、追加推力、即时重抛或抛掷队列。
- **其他交互入口**：不做摇晃手机抛掷、边缘长按入口或额外声音开关。
- **扩展风格系统**：V1 仅提供三种风格，不做下载更多币种、自定义图案或用户上传材质。
- **其他设备与方向**：不支持 iPad、Android、横屏或随设备旋转切换布局。

## 5. 开发与验收重点

- 正常落地与中断落地都应显示本次预先确定的结果，风格、手势力度和历史不影响概率。
- 三种风格都应满足完整的上划、落定、切换、保存及重新启动流程。
- 运动期间的再次上划被忽略，稳定后恢复操作，不出现补发抛掷。
- 首次上划引导只出现一次，隐藏风格切换不附带引导。
- 冷启动恢复最后结果并悬浮；后台中断后返回显示已落定结果，两者行为明确区分。
- 系统静音、减少动态效果及触觉不可用时，核心选择流程仍可完成。
- 启动速度、动画帧率、音画触觉同步误差、手势有效阈值及最低系统版本，进入真机原型阶段后确定具体验收数值与支持范围。
