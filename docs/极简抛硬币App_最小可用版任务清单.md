# 极简抛硬币 App 最小可用版任务清单

- 对应文档：《极简抛硬币 App V1 需求文档》《极简抛硬币 App 最小可用版技术文档》
- 采用方案：Swift + SwiftUI + RealityKit 精简版
- 任务数量：24 个，每个任务可在一次对话或一次提交内完成

---

## 0. 使用说明

### 0.1 三种验证方式

本清单的验收标准只用以下三种方式，都不需要你读懂代码：

| 方式 | 怎么操作 | 看什么 |
| --- | --- | --- |
| **真机查看** | 在 Xcode 顶部选择你的 iPhone，按 `⌘R` 运行 | 手机上的画面、声音、震动 |
| **自动测试** | 在 Xcode 中按 `⌘U` | 左侧"测试"面板（菱形图标）中，对应测试名称前出现绿色对勾即通过，红色叉号即失败 |
| **调试信息条** | 任务 14 完成后，开发版运行时屏幕底部会出现一行小字 | 当前状态、本次决定的结果、上划速度 |

> 调试信息条只在开发版出现，正式版不会出现，不违反"界面无文字"的需求。任务 24 会验证这一点。

### 0.2 每个任务的写法

- **依赖**：必须先完成的任务编号
- **要做什么**：可以直接交给开发者或 AI 编程助手的说明
- **涉及文件**：对应技术文档第 6 节的工程结构
- **验收标准**：你亲自操作就能确认的结果

### 0.3 建议的工作方式

- 每次只做一个任务，验收通过后再做下一个。
- 每完成一个任务，在 Xcode 中提交一次（Source Control → Commit），提交说明写上任务编号，例如"T07 随机器"。出问题时可以退回上一步。
- 把任务交给 AI 时，同时附上技术文档，并说明"只做这一个任务，不要改动其他功能"。

## 2. 任务详情

### 阶段一：工程准备

---

#### T01 创建工程并在真机运行

- **依赖**：无
- **要做什么**：
  1. 在 Mac 上安装 Xcode，用 Apple ID 登录（Xcode → Settings → Accounts）。
  2. 新建 iOS App 工程，名称 `CoinFlip`，界面选 SwiftUI，语言选 Swift，勾选"Include Tests"。
  3. 用数据线连接 iPhone，在手机上开启"开发者模式"（设置 → 隐私与安全性 → 开发者模式），并信任这台电脑。
  4. 在 Xcode 顶部选择你的 iPhone 运行。
- **涉及文件**：整个新工程
- **验收标准**：
  - [ ] 在 Xcode 选中你的 iPhone 按 `⌘R`，手机上打开一个显示 "Hello, world!" 的 App
  - [ ] 手机桌面上出现 CoinFlip 图标，断开数据线后点击图标仍能打开

> 免费 Apple ID 安装的 App 约 7 天后需要重新运行一次；上架需要付费开发者账号。

---

#### T02 工程基础设置：仅 iPhone、仅竖屏、全屏

- **依赖**：T01
- **要做什么**：
  1. 支持设备只保留 iPhone。
  2. 屏幕方向只保留"竖屏"（Portrait）。
  3. 隐藏状态栏。
  4. 把 "Hello, world!" 换成全屏纯黑背景，不显示任何文字。
- **涉及文件**：`App/CoinFlipApp.swift`、工程设置
- **验收标准**：
  - [ ] 打开 App，整屏纯黑，看不到时间、电量、信号等状态栏图标
  - [ ] 关闭手机的"竖排方向锁定"，把手机横过来，画面不跟着旋转
  - [ ] 屏幕上没有任何文字和按钮

#### T03 建立目录结构与测试环境

- **要做什么**：

- **涉及文件**：工程目录、`Tests/FlipPlannerTests.swift`
- **验收标准**：
  - [ ] Xcode 左侧文件列表中能看到上述 5 个文件夹
  - [ ] 按 `⌘U`，测试面板中 `testSetupWorks` 前显示绿色对勾

### 阶段二：核心逻辑（全部用自动测试验收）

---

---

#### T05 银币风格档案 `StyleProfile`

- **依赖**：T03

- **涉及文件**：`Model/StyleProfile.swift`
- **验收标准**：按 `⌘U`，以下测试全部通过

  - [ ] `testSilverBounciness`：`silver.bounciness` 大于 0 且小于 1
  - [ ] `testSilverId`：`silver.id` 等于 `"silver"`

#### T06 准备素材：贴图与音效

- **依赖**：T03
- **要做什么**：
  1. 准备两张原创正方形贴图：`sun_silver.png`（日面）、`moon_silver.png`（月面），不复刻任何真实货币图样。
  2. 准备一个短促的金属落地音效 `land_silver.wav`（或 `.caf`），使用可商用授权的素材或自行录制。
  3. 放入 `Resources` 文件夹，并确认已加入 App 目标。
  4. 写测试检查这三个文件能被 App 找到。
- **涉及文件**：`Resources/` 下三个文件
- **验收标准**：
  - [ ] 在访达中选中两张图片按空格预览，能看到日面和月面图案
  - [ ] 选中音效按空格预览，能听到撞击声，时长在 1 秒左右或以内
  - [ ] 按 `⌘U`，`testResourcesExist` 通过（三个文件都能在 App 内找到）

#### T07 随机器

- **依赖**：T04
- **要做什么**：在 `FlipPlanner` 中写 `decideResult() -> CoinFace`，只使用 `Bool.random()`，不加任何平衡逻辑。
- **涉及文件**：`Logic/FlipPlanner.swift`
- **验收标准**：按 `⌘U`，以下测试通过
  - [ ] `testResultIsFair`：调用 10000 次，日面次数在 4800 到 5200 之间
  - [ ] `testBothFacesAppear`：调用 100 次，日面和月面都至少出现一次
  - [ ] 连续按 `⌘U` 运行 5 次，以上测试每次都通过

#### T08 半圈数修正函数（最关键）

- **依赖**：T04
- **要做什么**：按技术文档 5.2 节写 `makeHalfTurns(baseHalfTurns:startFace:result:) -> Int`，并写测试。
- **涉及文件**：`Logic/FlipPlanner.swift`

  - [ ] 以上 8 行全部符合

#### T09 生成时间表 `FlipPlan`

- **依赖**：T05、T08
- **要做什么**：
  1. 按技术文档第 4 节定义 `FlipPlan`。
  2. 写 `makePlan(speed:startFace:result:style:) -> FlipPlan`：速度换算高度（夹在上下限之间）→ 换算飞行时长 → 由速度换算基础半圈数 → 用 T08 的函数修正 → 计算落地时刻、弹跳高度、停稳时刻。
- **涉及文件**：`Model/FlipPlan.swift`、`Logic/FlipPlanner.swift`
- **验收标准**：按 `⌘U`，以下测试通过
  - [ ] `testZeroSpeedUsesMinHeight`：速度输入 0，`height` 等于 `silver.minHeight`
  - [ ] `testHugeSpeedUsesMaxHeight`：速度输入 100000，`height` 等于 `silver.maxHeight`
  - [ ] `testFasterIsHigher`：速度 500 的高度不低于速度 200 的高度
  - [ ] `testTimeOrder`：任意速度下，`0 < landTime < endTime`
  - [ ] `testBounceHeight`：`bounceHeight` 等于 `height × silver.bounciness`
  - [ ] `testPlanKeepsResult`：输入的 `result` 与输出 plan 中的 `result` 相同

---

#### T10 结果一致性总测试

- **依赖**：T07、T09
- **要做什么**：
  1. 写 `finalFace(of plan: FlipPlan) -> CoinFace`：根据 `startFace` 和 `halfTurns` 的奇偶，算出动画结束时朝上的面。
  2. 写总测试：随机速度、随机起始面、随机结果，生成 1000 个时间表，逐个检查最终朝上的面等于结果。
- **涉及文件**：`Logic/FlipPlanner.swift`、`Tests/FlipPlannerTests.swift`
- **验收标准**：
  - [ ] `testFinalFaceAlwaysMatchesResult`：1000 次全部一致，测试通过
  - [ ] **反向验证**：临时把 T08 函数改成直接返回 `baseHalfTurns`（不修正），按 `⌘U`，此测试应变成红色叉号；改回后重新变绿。证明这个测试真的能抓到错误

> 这是整个项目最重要的测试。以后每次改动画、换素材、加风格后都要跑一遍。

#### T11 本机保存 `CoinStore`

- **依赖**：T04
- **要做什么**：用 UserDefaults 写 `save(_ face: CoinFace)`、`load() -> CoinFace?`、`clear()`，键名 `lastResult`。测试中使用独立的测试存储，不影响 App 的真实数据。
- **涉及文件**：`Logic/CoinStore.swift`
- **验收标准**：按 `⌘U`，以下测试通过
  - [ ] `testEmptyLoadsNil`：清空后读取，结果为空
  - [ ] `testSaveMoonLoadsMoon`：保存 `.moon` 后读取，得到 `.moon`
  - [ ] `testOverwrite`：先存 `.moon` 再存 `.sun`，读取得到 `.sun`

---

#### T12 状态管理 `CoinController`

- **依赖**：T07、T09、T11
- **要做什么**：写一个控制器，持有当前 `CoinPhase`，提供：
  - `start()`：从存储读取结果，有则进入 `resting(结果)`，无则进入 `waiting`
  - `requestFlip(speed:) -> FlipPlan?`：若处于 `flipping` 则返回空（忽略）；否则决定结果 → **立刻保存** → 生成时间表 → 进入 `flipping`
  - `finishFlip()`：进入 `resting(结果)`
  - `interrupt()`：若处于 `flipping`，直接进入 `resting(结果)`
- **涉及文件**：`Logic/CoinController.swift`、`Model/CoinPhase.swift`
- **验收标准**：按 `⌘U`，以下测试通过
  - [ ] `testStartWithoutSavedIsWaiting`：存储为空时 `start()`，状态为 `waiting`
  - [ ] `testStartWithSavedMoon`：存储为 `.moon` 时 `start()`，状态为 `resting(.moon)`
  - [ ] `testFlipFromWaiting`：`waiting` 时请求抛掷，返回时间表，状态变为 `flipping`
  - [ ] `testFlipIgnoredWhileFlipping`：`flipping` 时再次请求，返回空，状态和时间表都不变
  - [ ] `testResultSavedImmediately`：请求抛掷后、尚未 `finishFlip()` 时，存储中已是本次结果
  - [ ] `testFinishGoesResting`：`finishFlip()` 后状态为 `resting(本次结果)`
  - [ ] `testInterruptGoesResting`：抛掷中 `interrupt()`，状态为 `resting(本次结果)`，存储中也是本次结果
  - [ ] `testFlipFromResting`：`resting` 时请求抛掷，可以正常开始

### 阶段四：抛掷

---

#### T15 识别上划并测速

- **依赖**：T14
- **要做什么**：
  1. 在全屏范围识别上划手势，计算手指离开时的向上速度。
  2. 设置门槛：向上距离和速度都达到最小值才算有效上划。
  3. 有效上划时，把速度显示在调试信息条上（暂不抛掷）。
- **涉及文件**：`Scene/CoinSceneView.swift`
- **验收标准**：
  - [ ] 快速上划：调试信息条的"速度"更新为较大的数字
  - [ ] 缓慢上划：速度数字更新为较小的数字
  - [ ] 下划、左划、右划：速度数字不变
  - [ ] 轻点屏幕：速度数字不变
  - [ ] 手指轻微抖动（几毫米）后松开：速度数字不变

---

#### T16 接通抛掷：飞起、翻转、落地

- **依赖**：T10、T12、T13、T15
- **要做什么**：
  1. 有效上划时调用 `requestFlip(speed:)`，拿到时间表。
  2. 每一帧根据经过时间，按技术文档 5.4 节计算硬币高度（抛物线）和翻转角度（从 0 匀速增加到 `halfTurns × 180°`）。
  3. 到达 `landTime` 时硬币回到原位，角度停在最终值。
  4. 本任务先不做弹跳，落地即调用 `finishFlip()`。
- **涉及文件**：`Scene/CoinSceneView.swift`
- **验收标准**：
  - [ ] 上划后，调试信息条先显示本次结果，硬币随即飞起、翻转、落回
  - [ ] 连续抛 30 次，**每次**落定后朝上的面都和调试信息条显示的结果一致
  - [ ] 落定后调试信息条状态显示"静置中"
  - [ ] 硬币飞起最高处没有超出屏幕顶部

---

#### T17 落地小弹跳与角度归零

- **依赖**：T16
- **要做什么**：
  1. 在 `landTime` 到 `endTime` 之间，硬币保持朝向不变，做一次高度为 `bounceHeight` 的小弹跳。
  2. 到达 `endTime` 时，高度归零，角度**归零**为干净值（日面 0°、月面 180°），再调用 `finishFlip()`。
- **涉及文件**：`Scene/CoinSceneView.swift`
- **验收标准**：
  - [ ] 每次落地后能看到一次小弹跳，弹跳过程中朝上的面不变
  - [ ] 连续抛 100 次，第 100 次时硬币仍然平整居中，朝向与结果一致，没有歪斜
  - [ ] 调试信息条在弹跳结束后才变为"静置中"

---

#### T18 运动中忽略上划

- **依赖**：T16
