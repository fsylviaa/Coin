## 2. 实现过程中与原计划的偏差

记录在这里，是因为这些改动都有具体原因，以后回看才知道为什么这么做。

| 原计划 | 实际做法 | 原因 |
| --- | --- | --- |
| 硬币悬空正对镜头 | 躺在看不见的水平面上，镜头斜上方看 | 对照参考视频，"落在平面上"才有真实感 |
| 落地后弹三下 | 边缘先着地 → 打转摇摆 → 躺平，共 11 次磕碰 | 实测参考录音，真硬币几乎不弹，主要是边缘磕碰 |
| 镜头固定 | 落定后绕到上方并推近成特写 | 参考视频的分镜，也是"揭晓结果"的仪式感来源 |
| 等待时硬币悬浮呼吸 | 硬币静卧，改由镜头缓慢游移 | 硬币躺在平面上还浮起来，自相矛盾 |
| 只有落地一声 | 抛起 + 落地 + 一串磕碰 | 参考录音里抛起也有声音，且余韵很长 |
| 单一贴图 | 贴图 + 法线贴图 + 环境贴图 | 没有法线图，浮雕像印花；没有环境反射，金属发灰 |
| 弹性 0.2 | 0.055 | 真硬币落在硬平面上几乎不弹 |

## 3. T23 真机调手感

**依赖**：T01 的真机部分（手机连上、开发者模式、Team 签名）

### 要做什么

装到真 iPhone 上反复抛，只调数值，不改流程。可调的都在这几处：

| 文件 | 可调的东西 |
| --- | --- |
| `Model/StyleProfile.swift` | 抛起高度上下限、落地小跳的高度 |
| `Logic/FlipPlanner.swift` 开头 | 力度映射的速度区间、翻转圈数、下落减速、落地倾角、打转圈数、磕碰节奏 |
| `Scene/SwipeDetector.swift` 开头 | 上划的距离门槛、速度门槛、允许的倾斜 |
| `Scene/CoinSceneView.swift` 开头 | 镜头角度距离、推近速度、亮度 |
| `scripts/make_assets.py` | 贴图图案、环境明暗、音色 |

### 验收标准

- [ ] 轻轻一划：硬币低低抛起，翻转较少
- [ ] 用力一划：明显更高更快，但不飞出屏幕
- [ ] 从上划到停稳，最长一次在你能接受的等待时间内
- [ ] 上划的门槛合适：手抖不会误触发，正常一划一定能触发
- [ ] 震动的轻重和画面对得上
- [ ] 调完后 `./scripts/test.sh` 全部通过（特别是结果一致性那组）
- [ ] 连续玩 5 分钟没有觉得别扭的地方

### 可能要一并决定的

- **力度是否把"划的距离"也算进去**。现在只看抬手速度。改动集中在
  `FlipPlanner.forceFactor`，约十来行，不影响下游。

## 4. T24 完整验收与正式版检查

**依赖**：T23

### 要做什么

1. `./scripts/test.sh` 跑全部测试
2. 逐项执行技术文档第 8 节的真机验收清单
3. 在 Xcode 中切到正式版运行（Product → Scheme → Edit Scheme → Run →
   Build Configuration 改为 Release），确认调试信息条消失，完成后改回 Debug

### 验收标准

- [ ] 全部自动测试通过
- [ ] 技术文档第 8 节所有项目都已打勾
- [ ] 正式版运行：屏幕上只有硬币，没有调试信息条，没有任何文字
- [ ] 正式版运行：抛掷、声音、震动、保存、中断处理与开发版表现一致

## 5. 交给他人使用或上架之前，还必须补齐

这几项不在最小可用版范围内，但缺了会出问题：

| 项目 | 为什么必须 |
| --- | --- |
| **首次光点引导** | 界面上没有任何按钮，新用户不知道要上划 |
| **减少动态效果模式** | 系统辅助功能要求；开启时应改用简化动画 |
| **App 图标** | 现在是空白图标 |
| **付费开发者账号** | 免费 Apple ID 装的 App 约 7 天后失效，且无法上架 |

## 6. 日常命令

```bash
cd ~/CoinFlip
./scripts/test.sh    # 跑测试
./scripts/run.sh     # 在模拟器里打开
./scripts/doctor.sh  # 环境出问题时诊断
open CoinFlip.xcodeproj   # 用 Xcode 打开（真机运行走这里）
```

**真机运行**：Xcode 打开项目 → 左侧点最上方 CoinFlip → TARGETS → CoinFlip →
Signing & Capabilities → Team 选你的 Apple ID → 顶部设备选你的 iPhone → `⌘R`
